# 書籍と CML ラボファイルに関する訂正・補足事項

本ファイルでは、書籍内の初期コンフィグ記載と本リポジトリの CML 用 YAML ファイル（および CML 実機上の見え方）に関する訂正・補足事項をまとめています。

---

## Lab-07：SW1 の `ip routing` について（補足）

- **書籍の記載**：初期コンフィグの `[SW1]` に `ip routing` を記載しています。
- **CML 実機での挙動**：SW1 に使用している `ioll2-xe` イメージでは `ip routing` が既定で有効になっているため、`show running-config` には表示されません。
- **対応**：ルーテッドポート（`no switchport`）およびルーティング機能は初期状態で有効に動作しているため、`ip routing` を手動で再投入したり、ノード定義を変更したりする必要はありません。そのまま演習を進めていただけます。

## Lab-31：EEM タイマー設定の構文修正（訂正）

- **対象**：Lab-31（OSPFv2 Broadcast / DR 切り替え未完了）の初期コンフィグ
- **事象**：書籍の初期コンフィグに記載している `event timer countdown time 240` は、CML 起動時にタイマー名指定なしの不完全な設定として解釈される場合がありました。
- **対応**：本リポジトリの `labs/Lab-31.yaml` では、タイマー名を明示した以下の構文へ修正済みです。

```text
event timer countdown name PRIO time 240
```

※ リポジトリの YAML をそのままインポートしていただければ、手動での修正は不要です。
