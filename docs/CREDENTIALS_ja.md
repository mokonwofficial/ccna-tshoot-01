## 補足事項

- **Lab-42 の R2** および **Lab-49 の R1 / R2** は SSH クライアント側であり、演習用のローカルログインアカウントは設定されていません。
- **Lab-43** では R1 が SFTP クライアント、SRV1 が SFTP サーバです。
- **Lab-44 の PC1** に配置される `/home/cisco/test.txt` は、CML の Alpine 初期化仕様により所有者が `root:root`（権限 `644`）で生成されます。`cisco` ユーザーから読み取り可能であり SCP 演習に支障はありません（所有者を変更したい場合の手順は [MANUAL_SETUP_ja.md](MANUAL_SETUP_ja.md) を参照してください）。
- 各ノードへのコンソールアクセスは、機器の設定でコンソール認証が明示的に有効化されていない限り、上記の資格情報は不要です。
